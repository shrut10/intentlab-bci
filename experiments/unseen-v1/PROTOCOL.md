# Evaluation on unseen participants

Recorded 14 November 2026 before fitting any model or inspecting final participant outcomes

## Research question and scope

This study tests whether two fixed EEG methods can distinguish the left and right cued imagery tasks in people who contribute no data to model fitting, feature scaling, reference estimation or operating rule selection

The source is Dreyer2023, an independently collected public corpus with 87 participants across cohorts A, B and C, using the first two acquisition runs only; those runs contain sham feedback rather than no feedback, while the four later runs contain feedback conditions outside this comparison

The data distribution is the MOABB conversion mirrored on Hugging Face, with each archived participant file checked against independently obtained original OSF publisher hashes; the pinned revision, original links, licences, exact sizes and checksums are preserved in `source_manifest.json`

## Participant separation

The complete participant assignment is in `split_manifest.json`, generated by sorting a fixed SHA256 key within each source cohort before assigning the declared counts

Both runs from each person remain together, and no participant can contribute to more than one partition; source missing trials are recorded without replacing a person or changing the assignment

## Fixed methods

Each completed epoch extends from 0.5 to 4.5 seconds after the imagery cue at the source sampling rate of 512 Hz; the delayed start reduces direct cue onset exposure but does not demonstrate the absence of visual information

The reference is the average of all 27 EEG channels, followed by selection of the nine sensorimotor channels named in `protocol.json`; auxiliary eye and muscle channels are excluded, each channel is demeaned within its epoch, and a fourth order Butterworth filter retains 8 to 30 Hz using forward and reverse filtering before one RMS normalises the whole epoch

This is offline processing of a completed four second window, with no claim of causal streaming or live intention latency

The first model uses 27 log bandpower features, the second uses trace normalised OAS covariance with a Riemannian tangent reference fitted only on training participants; both apply training fitted scaling and logistic regression with C fixed at 1, without a parameter search

Training weights give each participant and each class equal total weight, with mean trial weight one; these weights also fit the tangent reference and feature scalers, while target batch adaptation is disabled and predictions must be invariant to other target trials in the batch

## Selection and final evaluation

The higher validation participant mean balanced accuracy selects the primary model, with an exact tie favouring bandpower; validation participants never enter a refit, and the selected model, all validation results and saved model hashes are committed before final participant EEG is accessed

The primary scientific target is a lower bound above 0.50 for the selected model's 95% test interval, obtained from 5,000 participant bootstrap resamples within source cohorts; this would support discrimination of these cued tasks in the sampled unseen people, rather than reliable control or clinical usefulness

Both methods are reported, with every participant's balanced accuracy, ordinary accuracy, AUC, Brier score and trial counts; their paired difference uses the same resampled people for both methods, and the cohort C results remain descriptive because the final sample contains only two people

Secondary confidence thresholds are chosen separately for each method using validation data only, under the exact coverage and participant inclusion requirements in `protocol.json`; failure uses the declared 0.75 fallback and is reported explicitly, with abstentions excluded from accepted accuracy rather than counted as correct

The final evaluation is inspected once and published regardless of whether either target is met; it will not be used to change the protocol, select a new subset of people or justify replacing the deployed model

## Sources and limitations

The [original dataset paper](https://doi.org/10.1038/s41597-023-02445-z) describes the cohort composition, tasks and feedback conditions, while the [2026 investigation of visual cue effects](https://doi.org/10.3389/fnrgo.2026.1804143) motivates the delayed epoch and the explicit restriction of claims to cued task discrimination

The [pyRiemann tangent space documentation](https://pyriemann.readthedocs.io/en/latest/generated/pyriemann.tangentspace.TangentSpace.html) explains the training reference and optional target update, which is disabled here; the source corpus is shared under CC BY 4.0, with attribution and transformation details retained in this study

The original PhysioNet decoder, its weights, serving transformations and prior study evidence remain unchanged; this experiment evaluates separately fitted classical models on a different acquisition setting and does not constitute an external validation of the deployed CNN

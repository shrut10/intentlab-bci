2 What the models receive

Dreyer and colleagues recorded left and right hand motor imagery from 87 participants using 27 scalp EEG channels at 512 Hz [1]; this experiment uses the first two acquisition runs, which include sham visual feedback, and excludes the later runs that provide actual feedback

Each example is a completed window from 0.5 to 4.5 seconds after the cue; processing is offline, so the report does not establish that an equivalent result would be available during acquisition or within a prospective control loop

$preprocessing_details

Two fixed models are compared: logistic regression on band power features, and logistic regression on covariance features mapped to a tangent space; every fitted transform uses training participants only; the covariance representation and its reference are fitted before validation or test data are transformed

Training observations are weighted so that every participant contributes equally and each of their two hand classes has equal weight; the same weights are passed to the tangent reference, the feature scalers and the classifiers

The covariance baseline draws on the EEG representations and tangent space approach studied by Barachant, Bonnet, Congedo and Jutten [2]; this implementation uses logistic regression and a separately specified evaluation protocol, with pyRiemann 0.12 configured as TangentSpace(metric='riemann', tsupdate=False) so that prediction retains the reference fitted on training participants [3]

The model with higher mean participant balanced accuracy on validation data defines the primary analysis; a separate probability threshold is selected for each of the two models using its own validation predictions, with both models and their thresholds fixed before the test partition is evaluated

$threshold_rule

The primary metric is the mean of each test participant's balanced accuracy, so every person receives equal weight; balanced accuracy is the average recall for the two hand classes, with a chance reference of 50%; Brier score measures squared probability error, where a lower value is better

5 What this result cannot establish

A cued imagery recording does not isolate intention from everything else happening during a trial; visual arrows, sham feedback, eye movements, muscle activity and participant behaviour may all affect the measured signal

Trocellier and colleagues show that visual cues in this dataset can affect EEG classification, particularly for deep learning models, and compare cue aligned windows with windows starting 0.5 seconds later [4]; the delayed start used here reduces direct inclusion of cue onset but does not prove that visual or other confounds have been removed

The trial windows contain requested left or right imagery, rather than continuous periods with and without a request to act; accepted predictions therefore do not measure unintended commands during rest, response time, spontaneous intention or reliable control of a physical device

This is one fixed split of one recording corpus, with limited representation in the smallest cohort; the uncertainty interval describes the reserved participants under the declared analysis and does not include all uncertainty from model development, recruitment or a different recording protocol

The source is an EDF conversion of the original deposit, obtained through a pinned public mirror; the archive hashes match the original conversion host's metadata, which establishes byte identity for those archives but does not independently validate every source annotation

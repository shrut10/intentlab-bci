04 · Interpretation

About the published study

The published study uses Zhou2016 recordings from four people, with separate sessions for training, validation and testing; the comparison asks whether a model trained with instructed rest emits fewer unwanted commands than one trained only to distinguish movement classes, while session separation assesses later recordings from these same people, rather than transfer to new participants

The operating rule is chosen using validation data and then kept fixed for the test session; a command needs a high enough score for the selected agreement time, with another command blocked until the previous direction is released and the cooldown has passed

Waiting can reduce unwanted commands while also leaving intended actions unanswered, so idle activations, missed cues, repeated commands and latency must be read together

The rest gate multiplies a movement probability by a separate task score, so its output is a decision score rather than a calibrated probability of the intended action

Movement cues show arrows while rest uses a black screen, so the task detector may partly distinguish visual stimulation or recording artefacts rather than intention alone; this study does not isolate the cause of that distinction

Latency is measured from an annotated cue to the first correct emitted command and is reported only for cues that receive one; it excludes any hardware, transmission or physical action delay; the number of contributing cues is shown beside the median, while idle command rates use all annotated rest time, including periods without predictions, so the exposure and gap figures are part of the result

Carrara and Papadopoulo, 2023 motivate evaluation through successive EEG windows with idle activity included; Liu and colleagues, 2026, preprint investigate separating rest, supported imagery and activity outside the supported classes; these works inform the evaluation question, while this study uses its own task detector and command metrics without reproducing either method

A replay with four participants cannot establish dependable assistive control; experimental instructions, gaze, muscle activity and session differences may influence the signals, and recorded rest does not provide a direct measure of an intention to remain still, while the original IntentLab decoder and its frozen results remain a separate experiment
